Desacoplamento total do rastreio e calibração do [TTEA](https://github.com/larvattea/) de qualquer interface de jogo.\
Código feito com base no [Ginga Divina](https://github.com/marcosoft47/exergamejam2025), projeto da Exergamejam de 2025.\
Assets para a tela de calibração inclusos, mas a implementação e uso fica por conta própria dos desenvolvedores.\
Esse sistema utiliza um cliente UDP que envia a posição dos pés para um servidor. 

> [!TIP]
> O projeto de template [TTEA.gd](https://github.com/groundsmind/TTEA.gd-Template) é um bom ponto de referência a respeito do uso do cliente e criação de um servidor.
